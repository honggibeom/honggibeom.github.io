    뉴스 감성 추론이 요청 스레드 위에서 제한 없이 돌고, 검색 요청마다 og:image 스레드풀을 새로 만들었다 버리고 있었다. ONNX 추론은 Semaphore(2)로 자리를 정하고 못 잡으면 감성 없이 응답하게, 이미지 풀은 공용 고정 풀 하나로 바꿨다. 그 뒤 k6 로 50VU 씩 400 까지 올려 보니 200VU 부터 502 가 났는데, 범인은 백엔드가 아니라 nginx 의 임시 포트 고갈이었다. keepalive 세 줄로 고친 뒤 400VU 까지 실패 0, 그래서 몇 명까지 받을 수 있는지까지.
